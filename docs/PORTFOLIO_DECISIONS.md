# 회사 업무와 연결한 포트폴리오 구성

기준일: 2026-10-10. 공고의 AI/Digital 기반 업무·운영 혁신 과제 발굴·기획을 위해, 출하 목표에 맞는 개선안을 비교하는 시제품을 만들었습니다. 이 문서는 **공식 자료의 사실, 직무 해석, 합성 실험, 제작 기여**를 구분합니다.

## 공고와 회사에서 확인한 것

[LS ELECTRIC 경영지원 DT 공식 공고](https://lselectric.recruiter.co.kr/career/jobs/129138)의 업무는 전사 DX 전략·로드맵 수립 지원, AI/Digital 기반 업무·운영 혁신 과제 발굴·기획, AX 업무 프로세스 최적화·거버넌스 구축, AI/DX 동향·선진사 벤치마킹입니다. 필수 조건은 AI/DX 기술·트렌드에 대한 관심과 지식이며, 전략기획·신사업·기술 리서치 경험과 생성형 AI/LLM 지식 등은 우대 사항입니다. ATS 원본 이미지의 DT 행을 직접 확인했습니다.

[Beyond X 공식 서비스 맵](https://beyondx-sf.ls-electric.com/solution/offerings.php)은 시뮬레이션 기반 생산성 진단과 제조 데이터 분석을 소개합니다. [시뮬레이션 진단 서비스](https://beyondx-sf.ls-electric.com/eng/solution/solution1_2.php)는 공정 모델링·분석과 개선 대안 검토를 다룹니다. 이 자료는 회사의 공개 서비스 방향이며, 경영지원 DT 부서가 해당 서비스의 개발·운영을 담당한다는 증거는 아닙니다.

[LS그룹의 2026-08-25 공식 발표](https://www.lsholdings.co.kr/ko/media/news/796b7478333462497437596168535a775869497a707a4a4e465433616e706c63)는 LS ELECTRIC의 IT서비스 자회사 LS ITC와 모티프테크놀로지스의 제조 AI 협력을 설명합니다. 과제 발굴·현장 적합성 및 효과의 단계적 검증·후속 협력 검토가 공개된 계획입니다. 특정 부서의 담당 여부나 CELLFORGE와의 연계는 확인되지 않았습니다.

## 직무에서 도출한 검토 문제

신입 DT 지원 업무를 **현업의 문제·요구·지표·자료 정리 → 개선 후보 비교 → 시험·승인 근거 준비**로 해석했습니다. 이는 JD를 바탕으로 한 추론이며 실제 배치 업무·조직·승인 권한의 확인은 필요합니다.

CELLFORGE가 다루는 질문은 “생산량만 보고 증설을 선택하면 출하 목표에 맞지 않을 수 있지 않을까?”입니다. 실제 LS 공장에 이 문제가 있다고 주장하지 않습니다. LS의 특정 제품·공정을 복제한 모델도 아닙니다. 로봇 셀 조립을 가상 사례로 삼아 개선안의 선택 근거를 준비하는 연습입니다.

## 왜 이 대안을 검증 후보로 골랐나

20분·주문 20대·시드 42의 합성 실험에서 기준 운영은 출하 가능 15대, 초기 암 설비 1개 추가는 18대입니다. 완성품 재사용은 완성 19대 중 6대를 설비로 써 출하 가능량이 13대입니다. 검사 실패 가정 12%→6%는 해당 시드에서 15대로 동일합니다. [원본 입력·전체 결과](DECISION_COMPARISON.md)와 [JSON](decision-comparison.json)을 함께 보존했습니다.

단기 출하 목표에 맞춰 **암 설비 추가를 다음 검증 후보**로 골랐습니다. 추가 설비는 이미 설치되어 시간 0부터 가동하는 가정이므로 실제 구매·설치 일정이나 경제성을 검증한 결과가 아닙니다. 실측 시간·주문·재검 기록과 투자·운영비, 공간·안전 조건을 확인하기 전에는 기존 조건 유지로 제안합니다. 품질 개선은 재검·불량 비용이 빠져 있으므로 가치가 없다고 결론 내리지 않습니다.

## 본인 판단과 AI 지원을 구분하기

[본인 결정 한 건의 실제 요청·수정 이유·반영 위치](PERSONAL_DECISION.md)를 별도로 기록했습니다. 포트폴리오 3장은 이 요청을 근거로 작성했습니다.

| --- | --- |
| 김현태 | 공장 주제·참고 영상·구현 방향을 제안했습니다. 회사 공고·업무·실제 쓸모를 충분히 확인하도록 요구했고, 이번에는 문제와 개선안 선택 이유가 보이도록 수정을 요청했습니다. 포트폴리오 1~2장의 구성 기준입니다. |
| 김현태 | 설비가 잘 보이는 사진과 쉬운 제목, 설명 대상의 사각형·연결선을 반복 요청했습니다. 큰 화면을 유지하도록 직접 지정했습니다. 1장의 화면과 모든 장의 관찰 안내, 3장의 본인 수정 요구에 반영했습니다. |

김현태가 직접 현업 인터뷰·실측 보정·설비 구매 승인·테스트 실행을 수행했다고 쓰지 않습니다. 3장의 담당자·자료 확인·소규모 시험·승인은 현장 적용 전 **제안**입니다.

LG전자 AX Workflow 교육 중 평택 공장 견학에서 디지털 트윈 기반 공장 시뮬레이션을 보고 영감을 받았다는 경험은 사용자 확인값입니다. 회사 시스템 구축·운영 경험이나 내부 데이터를 확보한 것으로 확대하지 않습니다.

## 확인한 범위

동일 입력 재현과 4개 대안의 정확한 수량, 여러 시점의 수량 보존, 기존 자동 테스트 12개를 확인했습니다. PDF는 총 3페이지이고 첫 장의 큰 실제 화면, 전체 화면 바깥 네 변 테두리, 대상 영역의 얇은 사각형과 설명 연결선을 유지했습니다. 모델은 실제 공장 데이터로 보정하지 않았으며 비용·물류·충돌을 계산하지 않습니다. PLC·MES·LLM은 연결하지 않았습니다.
