# 공개본 재현·화면 검수

검수일: 2026-10-07. 아래 수치는 모두 합성 모델 결과다.

공개 복사본을 로컬 HTTP 서버로 열고 실제 버튼·폼·시간 슬라이더를 조작했다. 화면 캡처에는 문서 배경과 구분되는 외곽 테두리를 붙였으며 UI 내용·텍스트·수치는 변경하지 않았다.

| 캡처 | 조건과 확인 결과 |
|---|---|
| 01-overview | 기본 조건 16분: 완료 13, 편입 4, 활성 자원 13 |
| 02-top-view | 동일 상태에서 평면 카메라로 전환 |
| 03-expansion-complete | 기본 조건 20분: 완료 19, 편입 6, 출하 13, 재공 1 |
| 04-baseline-complete | 편입 주기 0, 20분: 완료 15, 편입 0, 출하 15, 재공 5 |
| 05-supply-shortage | 부족 프리셋, 20분: 완료 3/6, 자재 대기 3 |
| 06-supply-recovered | 부족 조건 복구, 20분: 완료 6/6, 편입 2, 출하 4 |
| 07-inspection-rework | 검사 실패 프리셋, 6분: 셀 2 검사 실패·전자부 점검 후 재검 이벤트 |
| 08-layout-extra-resource | 초기 조립 자원 1개 추가, X=7.6/Z=8.0으로 배치 편집, 16분 활성 자원 14 |
| 09-mobile | 390×844 화면에서 기본 조건 16분; 목표 패널 전환 후 문서 폭·스크롤 폭 모두 390px |
| 10-invalid-input | 시드 -1 입력 후 공급 중단: 오류 표시, 마지막 유효 시드 42 복원·재생 정지 |

초기화는 16분에서 00:00·완료 0으로 돌아갔다. 브라우저 오류 로그는 0개였으며 모바일 크기 검수 후 뷰포트 설정을 해제했다.

`npm run compare`는 기본 브라우저 조건인 목표 20대·시드 42·충분한 재고·수동 초기 자원 없음으로 확장 유무를 비교한다. 엔진의 자체 기본 목표 8대와 구분한다. 시드 1–30의 대응 비교와 10/20/40분의 고정 주문 수 비교도 출력한다. 시드 변화는 모델 민감도 검토이며 현장 검증이나 신뢰구간이 아니다.

기존 내보내기 예제에는 수동 초기 자원 1개가 포함돼 위 기본 조건과 다르다. STL은 개념 프레임이며 실제 제조 승인 자료가 아니다. 모델 가정은 [MODEL.md](../MODEL.md), 기존 엔진·파일 검수는 [VERIFICATION.md](../VERIFICATION.md)에 있다.
